本书面向已有语言模型训练经验、希望进一步掌握智能体训练的工程师。这里的智能体会调用工具、读取结果，并通过多轮交互完成任务。我们从基本原理讲起，推导强化学习的核心方法，同时讨论它与 SFT、偏好学习、on-policy distillation 等后训练方法如何配合。

训练基础模型是我多年来的本职工作，但 agentic RL 并不是我过去的重心。这几年，agentic RL 和后训练的发展很快，我却一直很难找到一份系统的教程，能把原理、代码和实践中的取舍串起来讲清楚。于是就有了这个项目。我和 GPT-6 一起完成这份教程，既是给自己补课、梳理理解，也希望把学习过程中的心得分享出来。

全书围绕一个具体问题展开：**编程智能体修复一次 bug 的过程，如何变成模型的学习信号？** 我们沿着这条线，逐步拆解模型生成的 token、工具返回的结果、训练轨迹张量、验证器给出的奖励，以及最终的损失和参数更新。各章用 PyTorch 逐步搭建一套小型、经过测试的训练系统，推导之后紧接着可运行的实现，代码下方附上核验过的输出。把这些环节连起来，才能既解释算法为什么有效，也说清楚某种实现为什么会出问题。

## 学完后应具备的能力

完成代码实践和练习后，你应当能够：

- **搭建训练闭环：** 定义编程任务环境和验证器，采集多轮 rollout，构造训练张量，更新策略，并在留出任务上评测。
- **解释优化目标：** 推导策略梯度、advantage、PPO 和 GRPO；追踪哪些 token 参与损失计算，以及 mask、归一化和 KL 正则化如何改变更新。
- **做出工程决策：** 分析工具调用预算、奖励设计、长时程任务的回报归因、rollout 的时效性，以及推理与训练的一致性。
- **定位训练故障：** 结合日志和对照实验，排查奖励上涨但任务表现没有改善、奖励投机、熵坍缩和更新不稳定等问题。
- **评估新方法：** 分清已有结论、实现选择和尚无定论的问题，再设计实验检验替代方案。

本书希望帮助你具备参与后训练研究与工程的能力：实现一个方法，说明它的假设，检查实际行为，并验证改进是否有效。小型训练系统让你能掌握完整流程，真实模型实验则进一步展示模型自身的行为与实现细节。本页末尾会说明这些实验结果的适用范围。

## 本书的组织方式

本书逐章搭建**同一个系统**：

- **BugFix gym**（第 4 章）是一组小型 Python 修复任务。智能体使用 `read`、`test`、`edit` 和 `submit` 这几个工具来修复它们。测试会执行真实代码，隐藏测试用于检查公开用例之外的修复效果，而一个漏洞利用（exploit）操作让奖励投机真实地发生。
- **TinyAgent**（第 3 章）是一个小型 transformer 策略，在 CPU 上用强化学习训练约一分钟即可完成。它能复现大规模训练中出现的现象：格式学习、熵坍缩、长度效应、跨轮次的回报归因以及奖励投机。
- **真实模型实验**在模型特定行为起作用的地方使用真实的 Qwen3-0.6B 分词器和模型，例如对话模板、工具调用 token、重分词漂移，以及推理引擎与训练器之间的对数概率不一致。

每个机制都先推导，再在一个短代码块中从零实现，然后运行。其打印输出直接出现在代码下方。仿照 [D2L](https://github.com/d2l-ai/d2l-zh) 的做法，某一章构建的函数会标记为 `#@save` 并收集进 `agentrl` 包，因此后续章节直接调用 `arl.ppo_policy_loss(...)`，而不必重复实现。到了综合实战（capstone）一章，读者已经亲手写过训练栈的每一个部分。生成包按主题组织为 `policy.py`、`environments.py`、`trajectories.py`、`grpo.py` 等模块，`__init__.py` 只导出接口。模块索引 (`agentrl/README.md`)列出了章节与模块的对应关系。

每章都以**实践中的设计问题**收尾。这一节选取工程师真实遇到的问题，对每个问题给出症状、原因、可选方案和推荐的默认做法。之后每章还有小结和练习。[附录 B](/tutorial/zh/chapters/B-design-review) 收录了开放式的设计评审问题，并附参考答案。

## 运行代码

每个 Python 代码块都可以运行。检查器按顺序执行各章，从前面章节的 `#@save` 块重新构建 `agentrl`，并将每个代码块的标准输出与记录的输出进行比较：

```sh
scripts/remote_check.sh <workdir> [chapter-prefix ...]   # runs on the GPU host; CPU is enough
python3 scripts/build_library.py                         # regenerate agentrl/ from the chapters
scripts/remote_figures.sh <workdir> [chNN ...]           # regenerate data figures
python3 scripts/build_tutorial_site.py                   # regenerate the Mintlify edition in website/
```

[真实模型实验](/tutorial/zh/labs/README)在一块 H200 上用 BugFix gym 训练 Qwen3-0.6B，第 19 章报告了其实测结果。

[编辑指南](/tutorial/editorial-guide)规定了本书的写作约定，[来源台账](/tutorial/sources)记录了每一个外部来源、其查验日期以及查验范围。

## 实验能说明什么，不能说明什么

TinyAgent 实验均实际运行过，但模型和任务集都很小。它们用来解释机制、复现故障，不能作为大模型性能的基准证据。论文报告的结果会标注为文献报告并注明日期。建议会标注为本书的建议。环境只执行为本书编写的可信代码；第 4 章解释了真实的模型生成代码所需要的隔离。
