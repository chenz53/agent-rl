title: "A complete small rollout-and-update loop"
---

We now run a genuinely sampled on-policy learning loop in PyTorch. To make every step inspectable, the environment is a one-step categorical bandit: four possible actions with known rewards. It is an algorithm laboratory, not a simulated patient or a transformer agent.

## The complete cycle

A parameter vector defines the policy. Sample a group of actions from its categorical distribution. The environment maps those actions to terminal rewards. Compute leave-one-out advantages, recompute differentiable selected log-probabilities under the unchanged current policy, and apply one SGD update. Repeat with fresh samples; no sample reuse or importance ratios are needed here.

The best action has reward 1.0; the others have lower rewards. We fix a CPU seed and dtype. The printed result is a real tiny policy update, but its rewards are stipulated and it supplies no evidence of clinical or language-model capability.

## Why this is the first capstone

A successful loop verifies basic signs, sampling, detachment, and updates before involving tokenizer templates, tool execution, or distributed inference. Separating these sources of failure makes the later agent integration diagnosable.

```python
import torch
from nanoastra.posttraining import group_advantages
# A local generator avoids changing unrelated experiments' RNG state.
generator = torch.Generator().manual_seed(7)
logits = torch.nn.Parameter(torch.zeros(4, dtype=torch.float64))
optimizer = torch.optim.SGD([logits], lr=0.2)
reward_table = torch.tensor([0.0, 0.2, 1.0, -0.2], dtype=torch.float64)
before = logits.softmax(-1).detach().clone()
for step in range(80):
    actions = torch.multinomial(logits.detach().softmax(-1), 32, replacement=True, generator=generator)
    rewards = reward_table[actions].reshape(1, 32)
    advantage = group_advantages(rewards, leave_one_out=True).reshape(-1)
    sampled_logp = logits.log_softmax(-1)[actions]
    loss = -(advantage * sampled_logp).mean()
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
after = logits.softmax(-1).detach()
print("initial policy:", [round(v, 4) for v in before.tolist()])
print("trained policy:", [round(v, 4) for v in after.tolist()])
print("best action probability increased:", bool(after[2] > before[2]))
print("expected reward improved:", bool((after*reward_table).sum() > (before*reward_table).sum()))
```

Output:

```text
initial policy: [0.25, 0.25, 0.25, 0.25]
trained policy: [0.0274, 0.0331, 0.9169, 0.0226]
best action probability increased: True
expected reward improved: True
```

## Agent integration is a separate engineering milestone

The next domain experiment replaces the bandit with the oncology tool environment and the vector with a tokenizer-backed language model. It must preserve sampled IDs and old log-probabilities, execute bounded tools, score independent evidence/outcome signals, align masks, run the chosen update, and compare held-out performance. The current repository has not completed that full autonomous clinical training run.

Use existing verl for rollout/trainer infrastructure; use these PyTorch laboratories to audit objectives. Before a GPU run, fail fast on shifted targets, wrong grouping, tool-token leakage, incorrect denominator, or mismatched behavior probabilities. Keep model size, seeds, policy version, teacher access, reward components, and stop reasons in the experiment record.
