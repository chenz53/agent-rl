## Every mechanism has a coding question behind it

Why must the agent execute a test rather than claim it passed? Which generated tokens are actions? Why gather a selected log-probability? How does a verifier score become a gradient? Each chapter answers the question left by the previous chapter, using the same coding repair and visible function definitions.

The revised edition contains **15 chapters and 22 executed Python blocks**. Code has captured outputs; formulas use separate display-math delimiters; flow and sequence diagrams explain interaction and training. DeepSWE supplies a public infrastructure reference, while the experiments remain intentionally small enough to inspect.

Begin with [the coding task](/tutorial/chapters/01-coding-task), then follow [the reading order](/tutorial/README). The final lab trains a small patch-selection policy against executable tests. A full model-backed DeepSWE reproduction is outside the experiments completed here.
