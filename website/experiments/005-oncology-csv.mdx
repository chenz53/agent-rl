Date: 2026-09-28. The user requested English documentation and cancer prognosis reasoning beginning with realistic clinical `csv.gz` files.

## Artifacts

- Thirteen actual gzip CSV clinical tables plus one evaluator-only mortality/follow-up file.
- Deterministic synthetic generator, schema dictionary, point-in-time patient projection, and a separate survival-label helper.
- Scripted table queries using the existing real verl BaseTool adapter and an oncology field allowlist.
- Detailed English lesson on file parsing, timestamps, revisions, units, evidence, prognosis, and censoring.
- All repository Markdown documentation migrated to English, including historical discussions labeled as translations or summaries. Original prior text remains in Git history; historical raw experiment outputs remain unchanged.

The provisional task is 180-day all-cause mortality prognosis for a pretreatment metastatic NSCLC case at `2025-03-01T09:00:00Z`. All data and outcomes are invented. Two additional sparse patients exist only to demonstrate isolation and follow-up labels.

## Reproduction

From the repository root:

```sh
python3 scripts/generate_oncology_fixture.py
python3 scripts/demo_oncology.py --tables diagnosis labs vitals notes
python3 scripts/build_oncology_labels.py
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

In the prepared vp environment:

```sh
.venv/bin/python scripts/demo_oncology.py --verl --tables labs notes biomarkers medication_administrations mortality
.venv/bin/python scripts/check_historical_lesson_snippets.py
```

## Limits

No new dependencies, model inference, clinical scoring, or parameter update were needed. This is not an autonomous agent or calibrated survival model. No actual patient data, clinical expert review, real-data schema adapter, mortality ascertainment validation, or censoring-aware model evaluation is claimed.

The record tool enforces an application-level allowlist. A future agent must not also receive unrestricted filesystem access to the evaluator directory. The reader is a small in-memory teaching implementation, not a production clinical warehouse or patient simulator. Statistical prediction, causal treatment effects, and authored evidence summaries remain distinct tasks.
