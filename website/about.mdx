This reading edition teaches post-training entirely through coding tasks. The canonical chapters are in `tutorial/chapters/`; every teaching function is defined in its chapter. `scripts/check_tutorial_snippets.py` executes the trusted examples and verifies captured output. `scripts/build_tutorial_site.py` generates the Mintlify edition.

DeepSWE, rLLM, and R2E-Gym are public reference systems. The authored clamp problem makes concepts executable; it is not their dataset or benchmark. See the [source ledger](/tutorial/sources) and [editorial guide](/tutorial/editorial-guide).

The repository retains earlier material as historical project records. It is outside this edition's reading route and exported pages. The current experiment record is [009](/experiments/009-coding-tutorial).

The local Mintlify site has not been publicly hosted. Small coding-function execution uses trusted authored source strings; complete model-generated repair runs require isolated execution infrastructure and independent evaluation.
