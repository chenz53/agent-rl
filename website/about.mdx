title: "Repository, provenance, and scope"
---

The canonical repository is nanoAstra. `tutorial/chapters/` holds newly authored post-training chapters; `docs/lessons/` holds the continuous oncology case study. `src/nanoastra/posttraining.py` contains small PyTorch teaching primitives. `scripts/check_tutorial_snippets.py` executes trusted chapter code and verifies stdout. `scripts/build_tutorial_site.py` regenerates this reading edition.

Some original lessons refer to fixture or source directories. Those directory references lead here because this interface is a book, not a file browser. Open the local repository to inspect the full trees. Linked individual source files are provided as text downloads where applicable.

D2L informs the explanatory progression; its text and examples were not copied. See the [editorial policy](/tutorial/editorial-guide). All clinical fixtures are synthetic. Tiny optimizer demonstrations and author-reported benchmark results have separate evidence labels.

The Mintlify project is prepared locally. A hosted site has not been published. Hosting setup requires choosing a deployment destination; this repository does not invent a public GitHub URL or upload clinical data.
