# 第一课：把临床推理变成可训练的问题

状态：初稿。本文定义训练问题，不提供具体患者的诊疗建议。

## 1. 第一项区别：回答病例题与在病例中决策

如果模型一次看到全部病例材料，再输出诊断，我们首先面对的是固定输入上的预测或推理任务；它也可以用 RL 优化。

nanoAstra 的初始设计增加一个关键变量：模型需要决定下一步获取什么信息，并根据返回结果调整判断。我们研究的是这一序贯决策过程。多轮形式本身不保证更好的推理能力，需要实验验证其价值。

例如：初始主诉 → 请求某项病史 → 获取回答 → 请求已有检查结果 → 更新鉴别诊断 → 提交结论。

这里的检查请求只是离线环境中的信息访问，不等同于在医院执行检查。真实检查还涉及时间、风险、资源和状态变化，不能直接从这个简化环境外推。

## 2. 状态与历史

- `s`：环境内部的病例状态，包括尚未向 Agent 展示的信息。
- `o_t`：第 t 步返回的观测。
- `h_t`：Agent 实际可见的历史；如果有截断或摘要，它不一定等于完整历史。
- `a_t`：一次决策，例如请求信息、查询知识来源或提交最终回答。
- `πθ(a_t | h_t)`：策略模型给定可见历史时产生动作的分布。

初始环境可把病例设为静态隐藏状态。更真实的环境需要建模状态转移。部分可观测不意味着系统必须实现一个显式 belief-state 模型；历史条件策略也是一种实现方式。

## 3. 轨迹分布

令 `E` 表示环境，`x` 表示任务。以完整工具调用或回答为动作单位：

\[
p_\theta(\tau\mid x,E)=p(o_0\mid x,E)\prod_{t=0}^{T-1}\pi_\theta(a_t\mid h_t)P_E(o_{t+1}\mid h_t,a_t).
\]

当环境与评分规则不直接依赖参数 θ，且满足通常的可微与积分交换条件时，未折扣终局奖励的基本策略梯度为：

\[
\nabla_\theta J=\mathbb E_\tau\left[(R(\tau)-b(x))\sum_t\nabla_\theta\log\pi_\theta(a_t\mid h_t)\right].
\]

这里 baseline `b(x)` 不依赖采样动作，用于降低方差。该式是教学起点，不是最终采用的 PPO 或 GRPO 实现。使用逐步奖励时，需要进一步讨论 return-to-go 和 advantage。

一次文本动作的 log-probability 可分解成模型生成 token 的 log-probability 之和。工具返回会影响后续动作与奖励，但本身不是策略采样的动作 token；标准实现应正确 mask 环境输出。上下文中的生成内容、工具内容、截断和重新编码都需要保留清楚的来源与版本。

## 4. 科学目标与训练奖励

真实目标可能同时包括结论质量、合理的不确定性、信息获取效率和证据支持。可获得的训练信号可能只有诊断标签、专家评分或某些自动检查。

必须区分 `U(τ)`（真正关心的效用）与 `R(τ)`（可优化的评分）。不能默认二者一致。

| 候选评分 | 它可能遗漏什么 |
| --- | --- |
| 最终诊断正确 | 是否靠标签记忆或泄漏得到答案 |
| 查询次数少 | 是否过早停止、遗漏关键证据 |
| 引用真实存在 | 引用是否支持该病例中的结论 |
| judge 认为推理完整 | 是否只学会符合 judge 偏好的表达 |

初步评估分别报告各维度，之后再决定是否组合成训练奖励。任意加权和不是天然合理的临床效用模型。

## 5. 第一个有判别力的实验

在同一底座、同一任务拆分下比较：

1. 只给初始信息的模型。
2. 给定预先定义的完整允许信息的模型（信息充分的参考条件，不保证是性能上界）。
3. 能主动获取信息、尚未 RL 训练的 Agent。
4. 在相同工具与预算条件下经过 RL 的 Agent。

比较可以帮助分离信息可得性与策略优化的影响，但仍需控制采样预算、上下文长度、提示与数据污染；单次分数不能证明因果机制。

## 6. 本课讨论题

- 什么时候一条病例数据足够构成环境，什么时候必须有额外模拟器？
- 如果所有模型在完整信息条件下都失败，应优先改策略优化还是任务/能力基础？还需要什么证据？
- 如果 RL 后诊断正确率上升，同时查询次数翻倍，怎样判断收益？
- 若模型学会从字段缺失模式猜诊断，如何设计拆分与干预发现它？
