# Goals, background, and nanoAstra creation

Date: 2026-09-28. User statements are English translations of the original Chinese, not verbatim English quotes.

## User direction, translated

1. Learn Agentic RL training from the beginning with a tutor/domain expert, aiming for deep expertise in real-world training practice and underlying mechanisms.
2. The learner already has many years of foundation-model training experience; Agentic RL is a new focus. Biomedical domain agents are the preferred application.
3. Start with clinical reasoning and consolidate all discussions, lessons, documents, and code into a repository called nanoAstra, representing a simple agent built or fine-tuned from zero to one.

## Tutor response summary

The initial route covered RL foundations, optimization, LLM RL, multi-step agents, systems engineering, and research diagnosis. A coding-agent example introduced observations, actions, policies, trajectories, rewards, and credit assignment. That starting level was raised after the user described their expertise.

The revised teaching plan emphasizes environment definition, trajectory optimization, exploration, credit assignment, systems, and scientific evaluation. A gene-disease evidence example separates domain knowledge, information acquisition, and evidence judgment. It distinguishes true utility U from proxy reward R: existing citations, supporting citations, and causal evidence are not interchangeable.

## Historical action

Created the local repository, roadmap, first lesson, minimal design, reference index, and progress record. Clinical reasoning was the user's choice; offline record acquisition and differential diagnosis were the tutor's adjustable initial proposal. No agent had yet been implemented or trained at this milestone. Later decisions supersede that application scope.
